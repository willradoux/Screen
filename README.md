# Acelera Screen

Salas privadas de áudio, câmera e compartilhamento de tela para a comunidade AceleraDev, integradas ao Discord.

Estado: planejamento. As propostas de escopo, arquitetura e ambiente serão revisadas em pull request antes da implementação.

Frontend: React. Backend: TypeScript + Express. Infraestrutura inicial: VPS KVM1, com capacidade a validar.
