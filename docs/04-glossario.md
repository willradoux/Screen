# 04 - Glossário

| Termo | Significado |
|---|---|
| Guilda | Servidor do Discord (Acelera DEV) |
| Sala (Room) | Espaço de transmissão no Screem, ligado a um canal de voz (live) ou criado por admin (reunião) |
| Live | Sala criada automaticamente quando alguém entra em um canal de voz da categoria de lives |
| Reunião (Meeting) | Sala criada por admin via comando, com ou sem agendamento |
| Participante | Usuário conectado à sala no LiveKit |
| Publicar | Enviar mídia (câmera, tela, microfone) |
| Assistir | Receber mídia de outros |
| SFU | Selective Forwarding Unit: servidor que recebe a mídia e a repassa aos espectadores (LiveKit) |
| TURN/STUN | Servidores que ajudam a estabelecer conexão WebRTC atrás de NAT/firewall (Coturn) |
| Voice state | Estado de voz de um membro no Discord (em qual canal está, mutado, etc.) |
| Grace period | Tempo de tolerância (30 s) antes de remover quem saiu da call |
| Grant | Permissão embutida no token LiveKit (publicar, assistir, administrar) |
| Papel | `MEMBER`, `MOD` ou `ADMIN`, derivado dos cargos do Discord |
| Embed | Mensagem rica do Discord, usada com botão para abrir a sala |
| Auditoria | Registro imutável de ações de moderação e administração |
